# 狐绘万象

一个「放素材、发链接」的私人素材站。

把参考图和需求文稿按「角色 / 项目」两级丢进仓库，push 之后自动构建上线。画师拿到链接，输入角色名与完整项目名就能进入，随便看图、看文档、下载 —— 不需要注册，也不需要你开服务器。

---

## 它能做什么

- **纯静态上线**：没有数据库、没有账号系统、没有服务端进程，构建产物直接托管
- **两级口令**：站点入口要角色名，角色页要完整项目名（软门禁，见「安全边界」）
- **看图舒服**：4:3 预览不裁切长图、网格 / 列表切换、大图灯箱左右翻页，灯箱内可单击放大、滚轮缩放与按住拖动看细节
- **找东西快**：分类标签（全部 / 图片 / 文档 / 其他 / 目录）带数量、三种排序、文件名搜索并高亮命中词
- **发链接方便**：任何一张图都能生成可读直链，点一下即复制
- **引用目录**：一个 `.cmklink` 文件，就能把别处（甚至别的项目）的目录「像真实存在一样」显示在当前目录里

## 环境要求

- Node.js **18.17 或更高**（建议 20 LTS）
- 部署需要 GitHub 与 Vercel 账号（可选，本地也能完整跑）

## 快速开始

```bash
git clone <这个仓库>
cd ChamikoBrief
npm install
npm run dev            # 打开 http://localhost:3000
```

仓库自带一组示例素材（假名字），开箱即可走通全流程。输入框不区分大小写：

| 步骤 | 输入 |
| --- | --- |
| 首页「输入你的角色名」 | `alice` |
| 角色页「输入项目名」 | `demo-project` |

进去后你会看到：两张参考图、一份 Markdown 文稿、一个 `refs` 子目录，以及一个演示用的引用。

## 放你自己的素材

素材就是普通文件夹，放在 `public/` 下的两级目录里，层级不限：

```
public/
└── alice/                      ← 角色（第一级口令）
    └── demo-project/           ← 项目（第二级口令）
        ├── 参考图_01.png
        ├── brief.md
        ├── notes.txt
        └── refs/               ← 子目录随便建
            └── 参考图_03.png
```

提交即发布：

```bash
git add . && git commit -m "add demo-project" && git push
```

几条约定：

- 角色名、项目名就是文件夹名，**只有完整项目名才能进入**（大小写不限）
- 别在素材目录里放 `index.html` / `index.txt`，会和页面产物冲突
- 文件名里的 `#`、`?`、`%` 会被自动转义，中文名可以正常使用
- 本地想立刻看到新素材：先 `npm run prepare-brief` 再刷新（dev 服务器不会热感知新文件夹）
- 素材的「加入时间」由提交钩子记录：装好依赖后跑一次 `npm run hooks:install`（没启用也能用，只是显示提交时间）

### 用 `.cmklink` 做引用

想让某个目录里「直接出现」别处的目录，就在那儿放一个文本文件：

```
public/alice/demo-project/refs/demo.cmklink
   内容：alice/demo-project
```

- 内容是**相对 `public/` 的目标目录**，多个目标用 `|` 或换行分隔；`\` 与 `/` 都认
- 这个文件本身不显示在页面上；页面上出现的是它指向的目录，带一个灰色链接角标
- 点进去就像那个目录真的在这里：地址栏停在当前路径下，面包屑也不显示目标的父级，能一直往里走
- 引用里不能再进引用：目标目录内部的引用会显示成「引用 · 不可嵌套」，点不动
- 目标目录不存在时显示灰卡并标「目标不存在」，构建日志里也会提示

## 部署到 Vercel

1. 把仓库推到 GitHub（**建议设为私有**：门禁是软保护，别把不该公开的内容放进公开仓）
2. Vercel → New Project → Import 这个仓库
3. 框架选 Next.js，其余保持默认（构建命令 `npm run build`，产物目录 `out/`）
4. 之后每次 push 自动部署；更新素材同样是 push

## 安全边界（重要）

这个站是**软门禁**，不是权限系统：

- 页面的 URL 就是素材的真实路径（`/alice/demo-project/参考图_01.png`），知道路径的人可以直接打开
- 角色名与项目名以可逆混淆的方式存在构建产物里，能猜出完整名字的人本来就能拿到素材
- 因此：**只放你愿意分享的内容**，真正的机密文件不要放进来

## 代码地图

| 位置 | 作用 |
| --- | --- |
| `src/app/` | 路由：两级口令门禁页与浏览页 |
| `src/components/` | 卡片、列表行、灯箱、文本预览、右键菜单、面包屑等界面组件 |
| `src/lib/` | 路径与链接、文件类型判定、门禁名称保险箱等纯逻辑 |
| `scripts/prepare-brief.mjs` | 构建期：扫描素材、生成目录树、烘焙缩略图、解析 `.cmklink` |
| `public/` | 素材目录（把示例素材换成你自己的即可） |
